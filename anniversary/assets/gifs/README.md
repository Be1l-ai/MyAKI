# GIF Placeholders

This folder should contain the following animated GIFs:

## Required GIFs:

### Hero Section:
1. **hero-animation.gif** - Main landing page animation (hearts, sparkles, or romantic animation)

### Timeline Section:
2. **sparkle.gif** - For "The Day We Met" card
3. **hearts.gif** - For "We Became Official" card
4. **celebration.gif** - For "Our First Holiday" card
5. **love.gif** - For "Valentine's Day" card
6. **summer.gif** - For "Summer Adventures" card
7. **anniversary.gif** - For "One Year Together" card

### Future Section:
8. **future1.gif** - Floating animation 1
9. **future2.gif** - Floating animation 2
10. **future3.gif** - Floating animation 3

## Recommended Specs:
- Format: GIF
- Resolution: 400x400px to 600x600px
- File size: Under 2MB each
- Duration: 2-5 seconds loop

## Where to Find GIFs:
- GIPHY (https://giphy.com)
- Tenor (https://tenor.com)
- Search terms: "love", "hearts", "sparkle", "celebration", "romantic", "cute animation"

## Tips:
- Keep file sizes small for faster loading
- Choose GIFs that loop smoothly
- Match the mood of each section
- Preview before adding to ensure they're not too distracting
