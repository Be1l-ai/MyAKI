# Image Placeholders

This folder should contain the following images:

## Required Images:

1. **hero-background.jpg** (1920x1080px recommended)
   - Your couple photo for the landing page background
   - Should be high quality and meaningful

2. **memory1.jpg** - First Meeting (Sep 10, 2024)
3. **memory2.jpg** - We Became Official (Nov 17, 2024)
4. **memory3.jpg** - First Holiday Together
5. **memory4.jpg** - Valentine's Day
6. **memory5.jpg** - Summer Adventures
7. **memory6.jpg** - One Year Anniversary

8. **future1.jpg** - Future Dream/Plan 1
9. **future2.jpg** - Future Dream/Plan 2
10. **future3.jpg** - Future Dream/Plan 3

## Recommended Specs:
- Format: JPG or PNG
- Resolution: 1200x800px minimum
- File size: Under 500KB each (optimize for web)
- Aspect ratio: 3:2 or 16:9

## Tips:
- Use bright, clear photos
- Avoid too dark or blurry images
- Consider the composition for text overlays
- Compress images before uploading using tools like TinyPNG
